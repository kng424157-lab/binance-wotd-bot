Binance WOTD Solver - النسخة الأولى

الملفات:
- bot.py
- solver.py
- words.txt
- requirements.txt

لتشغيل البوت:
1. ثبّت المتطلبات: pip install -r requirements.txt
2. ضع توكن البوت في المتغير BOT_TOKEN
3. شغّل: python bot.py

ملاحظة: words.txt حالياً قائمة تجريبية، وسنستبدلها بقاعدة كلمات أكبر ونحسن خوارزمية الحروف المتكررة في المرحلة التالية.
